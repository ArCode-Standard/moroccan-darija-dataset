# معجم الدارجة المغربية | Moroccan Darija Lexicon

**ArCode Standard** — مورد معجمي أولي للتوثيق اللغوي والبحث في المعالجة الآلية للدارجة المغربية.

An initial lexical resource for documenting Moroccan Darija and supporting language technology research.

> **حالة المشروع:** إصدار البيانات المعلن 1.11.0، ويضم **1090 مدخلاً** موزعة على **38 فئة**، بالإضافة إلى **146 مثالاً سياقياً** في data/context-examples.json. هذا المورد معجم أولي، وليس corpus محادثات أو instruction dataset أو benchmark. ولا توجد نتائج منشورة تثبت كفايته وحده لتدريب نموذج لغوي موثوق أو تقييمه.

## المحتوى | What's included

يحتوي كل سجل في الإصدار الحالي على:

- id: معرّف فريد داخل مجموعة البيانات.
- category: الفئة الدلالية.
- darija_ar: الكلمة أو العبارة بالخط العربي.
- darija_latin: كتابة لاتينية استعمالية (عربيزي/فرنسية).
- fusha_ar: مقابل تقريبي أو صياغة بالفصحى.
- fr: مقابل أو ترجمة تحريرية بالفرنسية.
- register: تصنيف المستوى اللغوي: `darija` (دارجة خالصة)، `shared` (مشتركة بين الدارجة والفصحى)، `fusha` (فصحى صريحة). مطبَّق على كل المدخلات (1090) منذ 1.11.0: shared 603 / darija 471 / fusha 16.

قد لا تكون العلاقة بين الكلمة ومقابلها بالفصحى أو الفرنسية واحداً لواحد؛ فالمعنى والاستعمال قد يتغيران بحسب السياق.

### مثال على سجل

~~~json
{
  "id": 1,
  "category": "تحيات",
  "darija_ar": "السلام عليكم",
  "darija_latin": "salam 3likoum",
  "fusha_ar": "السلام عليكم",
  "fr": "Bonjour / paix sur vous"
}
~~~

## الكتابة اللاتينية وعربيزي | Latin writing

الكتابة اللاتينية في الدارجة المغربية **غير موحّدة ومتعددة البدائل**. قد يكتب المتحدثون الصوت نفسه بطرق مختلفة؛ لذلك يحتفظ المشروع بالصيغة الأصلية التي يقدمها المساهم، ولا يفرض تهجئة واحدة أو تطبيعاً آلياً.

أمثلة موثقة في إرشادات المشروع:

| الحرف/الصوت | تمثيلات ممكنة في نطاق الدليل |
|---|---|
| غ | gh أو 4 |
| ش | ch أو x |
| ح | 7 |
| خ | kh |
| ع | 3 |
| ق | 9 |

أمثلة على اختلاف الكتابة مع بقاء المقصود:

- «كنبغيك»: Kanbgik أو Kanb4ik.
- «ما عرفتش»: ma3raftch أو ma3raftx.

هذه أمثلة وصفية وليست قواعد تحويل شاملة أو إلزامية. لا ينبغي استنتاج صحة كلمة أو دمج سجلين اعتماداً على التشابه اللاتيني وحده.

**اقرأ:** [دليل الكتابة اللاتينية للدارجة المغربية](docs/TRANSLITERATION_STANDARD.md).

## البدء | Quick start

يتطلب تشغيل المدقق تثبيت اعتماد JSON Schema:

~~~bash
git clone https://github.com/ArCode-Standard/moroccan-darija-dataset.git
cd moroccan-darija-dataset
python -m pip install -r requirements.txt
~~~

عرض عدد المدخلات:

~~~bash
jq '.entries | length' data/moroccan-darija.json
~~~

عرض مدخلات فئة محددة:

~~~bash
jq '.entries[] | select(.category == "الوقت")' data/moroccan-darija.json
~~~

قراءة الملف باستخدام Python:

~~~python
import json

with open("data/moroccan-darija.json", encoding="utf-8") as file:
    dataset = json.load(file)

for entry in dataset["entries"]:
    print(entry["darija_ar"], "→", entry["fr"])
~~~

## المصادر والإسناد | Sources & attribution

- **DODa — Darija Open Dataset** (جزء من المفردات): https://github.com/darija-open-dataset/dataset — مرخّص CC BY-NC 4.0، مع الإسناد المطلوب بموجبه.
- **mylanguages.org** و**ilanguages.org**: صفحات تعلّم الدارجة (مفردات وعبارات أساسية للاستعمال التعليمي).
- **translatordarija.com**: قاموس الدارجة (فئات الطعام والوقت).
- **Wattpad**: استُخرجت **126 مفردة** من جمل دارجة في **160 قصة** (34,854 جملة) منشورة على wattpad.com بعد تصفية آلية للنصوص الفارسية والإنجليزية والترويجية؛ **لا يُعاد نشر نصوص القصص**، وحقوقها محفوظة لمؤلفيها.
- **Peace Corps Morocco — Moroccan Arabic Textbook (2011)**: 37 مفردة من مسرد الأفعال (ص.163)؛ كتيّب حكومي أمريكي (ملك عام)، والمفردات/الترجمات حُرِّرت داخل المشروع تحت رخصة التجميع.
- الكتابة اللاتينية والفصحى والفرنسية تحرير يدوي/آلي للمشروع، وليست منقولة من مصدر محمي.

## سجل المصدر والحقوق لكل مدخل | Per-entry provenance

منذ الإصدار **1.4.0** يحمل كل مدخل كائني `provenance` و`review` وفق [المخطط](data/schema.json):

~~~json
{
  "id": 1,
  "darija_ar": "السلام عليكم",
  "darija_latin": "salam 3likoum",
  "fusha_ar": "السلام عليكم",
  "fr": "Bonjour / paix sur vous",
  "provenance": {
    "source_type": "original",
    "source_name": "ArCode Standard — تحرير داخلي",
    "rights_holder": "ArCode Standard",
    "redistribution_permission": "allowed",
    "training_permission": "allowed",
    "commercial_permission": "not_allowed",
    "license": "CC BY-NC 4.0",
    "notes": "مفردة حُرِّرت داخل المشروع ولم تُنسب إلى مصدر خارجي."
  },
  "review": {
    "status": "pending",
    "notes": "لم تخضع لمراجعة بشرية مستقلة بعد."
  }
}
~~~

توزيع المصادر في هذا الإصدار:

| نوع المصدر | العدد | الأذونات المسجلة |
|---|---:|---|
| `original` — تحرير داخل المشروع | 656 | إعادة توزيع وتدريب: allowed؛ تجاري: not_allowed |
| `dictionary` — DODa (CC BY-NC 4.0) | 271 | إعادة توزيع وتدريب: allowed؛ تجاري: not_allowed |
| `web` — اكتمل التوثيق، لا مدخلات متبقية | 0 | — |
| `corpus` — Wattpad (مفردات مستخرجة من القصص) | 126 | المصدر: **Wattpad** (نصوص القصص غير مدرجة)؛ إعادة توزيع وتدريب: allowed؛ تجاري: not_allowed |
| `other` — Peace Corps Morocco (2011) | 37 | كتيّب حكومي أمريكي (ملك عام)؛ إعادة توزيع وتدريب: allowed؛ تجاري: not_allowed |

**قواعد القراءة:**
- القيمة `unknown` في حقل الأذونات **ليست** إذناً؛ تعني أن الحالة الحقوقية لم تُتحقق بعد. لم تبق أي مدخلة بحالة `unknown` بعد اكتمال إعادة التوثيق في 1.9.3. مدخلات Wattpad مكتوب مصدرها صراحةً **Wattpad** وأذوناتها مسجلة.
- `review.status = pending` لكل المدخلات حالياً: لم تُجرَ مراجعة بشرية مستقلة بعد.
- لا يعني سجل المصدر أن المقابل بالفصحى أو الفرنسي أُنشئ داخل المشروع؛ قد تكون له حقوق مستقلة.
- سياسة التوثيق الكاملة في [docs/DATA_PROVENANCE_AND_RIGHTS.md](docs/DATA_PROVENANCE_AND_RIGHTS.md).

## أسئلة شائعة حول المصادر | Sources FAQ

**ما الفكرة بجملة واحدة؟**
لكل كلمة «بطاقة مصدر» تقول: من أين جاءت؟ وهل يُسمح بإعادة استخدامها؟ ومن راجعها؟ وهذه هي الحقول `provenance` و`review`.

**ماذا يعني كل حقل؟**

| الحقل | المعنى |
|---|---|
| `source_type` | نوع المصدر: `original` (تحرير داخلي)، `dictionary` (قاموس)، `web` (موقع)، `corpus` (نصوص قصص). |
| `source_name` | الاسم الظاهر: «ArCode Standard — تحرير داخلي»، «DODa»، «Wattpad»، «mylanguages.org». |
| `source_url` | رابط المصدر عند وجوده. |
| `accessed_at` | تاريخ الوصول إلى المعلومة. |
| `rights_holder` | صاحب الحق. |
| `redistribution_permission` | هل يُسمح بإعادة النشر ضمن المجموعة؟ |
| `training_permission` | هل يُسمح باستخدامها لتدريب النماذج؟ |
| `commercial_permission` | هل يُسمح بالاستخدام التجاري؟ |
| `license` | الترخيص المطبق. |
| `review.status` | حالة المراجعة البشرية (`pending` = لم تُراجع بعد). |

**لماذا تختلف القيم؟**
- **656 (تحرير داخلي):** حُرِّرت داخل المشروع، فتُرخَّص تحت CC BY-NC: إعادة توزيع وتدريب مسموحان، والتجاري ممنوع.
- **271 (DODa):** المصدر نفسه CC BY-NC 4.0، فالحقوق واضحة بشرط الإسناد ومنع التجاري.
 - **126 (Wattpad):** أُخذت الكلمات المفردة فقط (43 في 1.6.0 و49 في 1.7.0 بعد توسيع corpus إلى 160 قصة)، ونصوص القصص لم تُنشر؛ المفردات والترجمات تحرير المشروع.
- **37 (Peace Corps 2011):** كتيّب حكومي أمريكي (ملك عام)؛ المفردات والترجمات حُرِّرت داخل المشروع تحت رخصة التجميع.
- **0 (مواقع تعليمية):** اكتمل توثيق الـ105 كلها في 1.9.0–1.9.3: 34 أُعيد توثيقها من DODa و71 أُعيدت صياغتها تحريرياً؛ لا تبقى مدخلات بحقوق غير محسومة. التفاصيل: [docs/RIGHTS_INVENTORY_2026-11.md](docs/RIGHTS_INVENTORY_2026-11.md).

**كيف أتحقق من كلمة؟**
افتح `data/moroccan-darija.json`، ابحث عن الكلمة، واقرأ `provenance` و`review`. للتفاصيل: [docs/DATA_PROVENANCE_AND_RIGHTS.md](docs/DATA_PROVENANCE_AND_RIGHTS.md).

**ما الذي لم يُنجز بعد؟**
- `unknown` في مدخلات المواقع يحتاج مراجعة شروط الاستخدام.
- كل السجلات `pending`: لا مراجعة بشرية مستقلة بعد.
- لا يوجد بعد رابط الصفحة الدقيقة لكل كلمة من المصادر الويبية.

## المنهجية وحدود البيانات | Methodology and limitations

وفق المنهجية المعلنة لهذا الإصدار:

- جُمعت المفردات والعبارات وحُررت يدوياً.
- أضيفت مقابلات بالفصحى وترجمات فرنسية تحريرية.
- أُجريت مراجعات آلية للبنية، مثل صحة JSON وتسلسل المعرّفات وتكرار المدخلات.
- يذكر سجل المشروع الاستعانة بمصادر معجمية مفتوحة للتحقق الجزئي، ومنذ الإصدار 1.4.0 يحمل كل مدخل سجلاً للحقوق والمصادر ومؤشر حالة مراجعة.

ينبغي قراءة هذه الحدود قبل استخدام البيانات:

1. المعجم أولي ولا يمثل جميع مفردات الدارجة المغربية أو تنوعاتها.
2. التغطية الجهوية والاجتماعية غير مقاسة كمياً؛ فلا يمكن استنتاج تمثيل متوازن لمناطق المغرب.
3. يحمل كل سجل سجلاً للمصدر والحقوق، لكن حقول المنطقة والنبرة ونوع التعبير ما زالت غير مكتملة؛ الأمثلة السياقية (146 مثالاً تحريرياً) في ملف مستقل `data/context-examples.json`.
4. الكتابة اللاتينية متعددة البدائل؛ ولا يعتمد المشروع تهجئة معيارية موحدة.
5. المقابلات بالفصحى والترجمات الفرنسية تقريبية وقد تتعدد بحسب السياق.
6. لا توجد مجموعة اختبار مستقلة أو benchmark أو نتائج تقييم بشرية منشورة.
7. لم تُنشر مراجعة لغوية مستقلة موثقة لكل سجل.

للتفاصيل، راجع [بطاقة مجموعة البيانات](DATASET_CARD.md) و[تقرير الجودة](docs/QUALITY_AUDIT_2026-10.md).
