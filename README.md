# معجم الدارجة المغربية | Moroccan Darija Lexicon

**ArCode Standard** — مورد معجمي أولي للتوثيق اللغوي والبحث في المعالجة الآلية للدارجة المغربية.

An initial lexical resource for documenting Moroccan Darija and supporting language technology research.

> **حالة المشروع:** إصدار البيانات المعلن 1.2.0، ويضم **887 مدخلاً** موزعة على **38 فئة**. هذا المورد معجم أولي، وليس corpus محادثات أو instruction dataset أو benchmark. ولا توجد نتائج منشورة تثبت كفايته وحده لتدريب نموذج لغوي موثوق أو تقييمه.

## المحتوى | What's included

يحتوي كل سجل في الإصدار الحالي على:

- id: معرّف فريد داخل مجموعة البيانات.
- category: الفئة الدلالية.
- darija_ar: الكلمة أو العبارة بالخط العربي.
- darija_latin: كتابة لاتينية استعمالية (عربيزي/فرنسية).
- fusha_ar: مقابل تقريبي أو صياغة بالفصحى.
- fr: مقابل أو ترجمة تحريرية بالفرنسية.

قد لا تكون العلاقة بين الكلمة ومقابلها بالفصحى أو الفرنسية واحداً لواحد؛ فالمعنى والاستعمال قد يتغيران بحسب السياق.

### مثال على سجل

~~~json
{
  "id": 1,
  "category": "تحيات",
  "darija_ar": "السلام عليكم",
  "darija_latin": "salam 3likoum",
  "fusha_ar": "السلام عليكم",
  "fr": "Bonjour / paix sur vous"
}
~~~

## الكتابة اللاتينية وعربيزي | Latin writing

الكتابة اللاتينية في الدارجة المغربية **غير موحّدة ومتعددة البدائل**. قد يكتب المتحدثون الصوت نفسه بطرق مختلفة؛ لذلك يحتفظ المشروع بالصيغة الأصلية التي يقدمها المساهم، ولا يفرض تهجئة واحدة أو تطبيعاً آلياً.

أمثلة موثقة في إرشادات المشروع:

| الحرف/الصوت | تمثيلات ممكنة في نطاق الدليل |
|---|---|
| غ | gh أو 4 |
| ش | ch أو x |
| ح | 7 |
| خ | kh |
| ع | 3 |
| ق | 9 |

أمثلة على اختلاف الكتابة مع بقاء المقصود:

- «كنبغيك»: Kanbgik أو Kanb4ik.
- «ما عرفتش»: ma3raftch أو ma3raftx.

هذه أمثلة وصفية وليست قواعد تحويل شاملة أو إلزامية. لا ينبغي استنتاج صحة كلمة أو دمج سجلين اعتماداً على التشابه اللاتيني وحده.

**اقرأ:** [دليل الكتابة اللاتينية للدارجة المغربية](docs/TRANSLITERATION_STANDARD.md).

## البدء | Quick start

لا يحتاج استعراض البيانات إلى تثبيت حزم Python خارجية:

~~~bash
git clone https://github.com/ArCode-Standard/moroccan-darija-dataset.git
cd moroccan-darija-dataset
~~~

عرض عدد المدخلات:

~~~bash
jq '.entries | length' data/moroccan-darija.json
~~~

عرض مدخلات فئة محددة:

~~~bash
jq '.entries[] | select(.category == "الوقت")' data/moroccan-darija.json
~~~

قراءة الملف باستخدام Python:

~~~python
import json

with open("data/moroccan-darija.json", encoding="utf-8") as file:
    dataset = json.load(file)

for entry in dataset["entries"]:
    print(entry["darija_ar"], "→", entry["fr"])
~~~

## التحقق والاختبارات | Validation

شغّل الأوامر التالية من جذر المستودع:

~~~bash
python scripts/validate_dataset.py
python -m unittest discover -s tests -v
~~~

يتحقق المدقق من سلامة JSON وبنية البيانات وعدد المدخلات والفئات وفريدة المعرّفات واتساق أعداد الفئات. كما يشغّل GitHub Actions الفحوصات عند تغيير الملفات ذات الصلة.

**حدود مهمة:** نجاح الاختبارات البنيوية لا يثبت صحة الكلمة لغوياً، أو شيوعها، أو تمثيلها لمنطقة معينة، ولا يثبت حقوق استخدامها. كما لا ينبغي للمدقق فرض صيغة لاتينية واحدة أو رفض البدائل الكتابية لمجرد اختلافها.

## المنهجية وحدود البيانات | Methodology and limitations

وفق المنهجية المعلنة لهذا الإصدار:

- جُمعت المفردات والعبارات وحُررت يدوياً.
- أضيفت مقابلات بالفصحى وترجمات فرنسية تحريرية.
- أُجريت مراجعات آلية للبنية، مثل صحة JSON وتسلسل المعرّفات وتكرار المدخلات.
- يذكر سجل المشروع الاستعانة بمصادر معجمية مفتوحة للتحقق الجزئي، لكن الإصدار الحالي لا يتضمن سجلاً موثقاً على مستوى كل مدخل يحدد المصدر ورابطه ونوع الإذن والمراجع.

ينبغي قراءة هذه الحدود قبل استخدام البيانات:

1. المعجم أولي ولا يمثل جميع مفردات الدارجة المغربية أو تنوعاتها.
2. التغطية الجهوية والاجتماعية غير مقاسة كمياً؛ فلا يمكن استنتاج تمثيل متوازن لمناطق المغرب.
3. لا تتضمن جميع السجلات حقولاً موثقة للسياق أو المنطقة أو النبرة أو نوع التعبير أو المصدر.
4. الكتابة اللاتينية متعددة البدائل؛ ولا يعتمد المشروع تهجئة معيارية موحدة.
5. المقابلات بالفصحى والترجمات الفرنسية تقريبية وقد تتعدد بحسب السياق.
6. لا توجد مجموعة اختبار مستقلة أو benchmark أو نتائج تقييم بشرية منشورة.
7. لم تُنشر مراجعة لغوية مستقلة موثقة لكل سجل.

للتفاصيل، راجع [بطاقة مجموعة البيانات](DATASET_CARD.md) و[تقرير الجودة](docs/QUALITY_AUDIT_2026-10.md).
