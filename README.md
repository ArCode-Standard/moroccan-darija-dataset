# معجم الدارجة المغربية — Moroccan Darija Lexicon

مجموعة معطيات معجمية أولية للدارجة المغربية، أنشأها ArCode Standard لدعم التوثيق اللغوي والبحث في المعالجة الآلية للغة.

An initial lexical resource for Moroccan Darija, maintained by ArCode Standard to support language documentation and NLP research.

> **حالة المجموعة / Dataset status:** إصدار معجمي أولي يضم 887 مدخلاً. لا يُعدّ هذا الإصدار corpus محادثات، أو مجموعة بيانات تعليمات (instruction dataset)، أو benchmark، ولا توجد نتائج منشورة تثبت كفايته لتدريب أو تقييم نموذج لغوي موثوق.

## بنية الملف / File structure

```json
{
  "meta": {},
  "categories": [{ "category": "تحيات", "count": 18 }],
  "entries": [
    {
      "id": 1,
      "category": "تحيات",
      "darija_ar": "السلام عليكم",
      "darija_latin": "salam 3likoum",
      "fusha_ar": "السلام عليكم",
      "fr": "Bonjour / paix sur vous"
    }
  ]
}
```

### الحقول / Fields

| الحقل | الوصف |
|---|---|
| `id` | معرّف تسلسلي فريد داخل الإصدار |
| `category` | الفئة الدلالية |
| `darija_ar` | الكلمة أو العبارة بالخط العربي |
| `darija_latin` | الكتابة اللاتينية الاستعمالية (عربيزي/فرنسية) |
| `fusha_ar` | مقابل تقريبي أو صياغة بالفصحى |
| `fr` | مقابل أو ترجمة تحريرية بالفرنسية |

## الكتابة اللاتينية / Transliteration

الكتابة اللاتينية تمثيل استعمالي مبسّط، وليست نظاماً معيارياً أو تحويلاً صوتياً مضبوطاً. قد تختلف كتابة الكلمة نفسها بين المتحدثين والمناطق والمنصات.

| الرمز | التمثيل المقصود |
|---|---|
| `3` | ع |
| `4` | غ في بعض الاستعمالات |
| `7` | ح |
| `9` | ق في بعض الاستعمالات |
| `kh` | خ |
| `gh` | غ |
| `ch` | ش |
| `ou` | و في بعض الكتابات |
| `y` | ي في بعض الكتابات |

هذه أمثلة وصفية وليست قواعد إلزامية؛ وقد يحمل الرمز الواحد أكثر من استعمال في الكتابة غير المعيارية.

## الاستعمال / Usage

```bash
# عدد المدخلات
jq '.entries | length' data/moroccan-darija.json

# عرض مدخلات فئة محددة
jq '.entries[] | select(.category == "الوقت")' data/moroccan-darija.json
```

```python
import json

with open("data/moroccan-darija.json", encoding="utf-8") as f:
    data = json.load(f)

for entry in data["entries"]:
    print(entry["darija_ar"], "→", entry["fr"])
```

## المنهجية / Methodology

وفق المنهجية المعلنة لهذا الإصدار:

- جُمعت المفردات والعبارات وحررت يدوياً.
- أُضيفت مقابلات بالفصحى وترجمات فرنسية تحريرية.
- أُجريت مراجعات آلية للبنية، مثل صحة JSON وتسلسل المعرّفات وتكرار المدخلات.
- يذكر سجل المشروع الاستعانة بمصادر معجمية مفتوحة للتحقق الجزئي؛ ولا يتضمن الإصدار الحالي سجلاً على مستوى كل مدخل يحدد المصدر أو رابط المصدر أو نوع الإذن أو المراجع.

**تنبيه منهجي:** الفحوصات البنيوية لا تثبت صحة المدخل لغوياً، أو شيوعه، أو ملاءمته لمنطقة بعينها. كما أن وصف التحرير بأنه يدوي لا يعادل مراجعة لغوية مستقلة موثقة لكل سجل.

## حدود المعطيات / Limitations

- المجموعة معجم أولي موسّع، وليست تمثيلاً شاملاً للدارجة المغربية.
- لا تتضمن حالياً حقولاً منهجية لكل سجل لتوثيق المنطقة أو السياق أو النبرة أو نوع التعبير أو المصدر أو المراجع.
- التغطية الجهوية والاجتماعية غير مقاسة كمياً؛ ولا ينبغي استنتاج تمثيل متوازن لمناطق المغرب.
- الكتابة اللاتينية غير موحّدة، ولا توجد حالياً سياسة تطبيع معيارية ملزمة.
- المقابلات بالفصحى والترجمات الفرنسية قد تكون تقريبية ومتعددة بحسب السياق.
- لا توجد في هذا المستودع مجموعة اختبار مستقلة أو benchmark أو نتائج تقييم بشرية منشورة.
- لا ينبغي وصف المجموعة وحدها بأنها كافية لتدريب نموذج لغوي موثوق أو قياس أدائه.

للاطلاع على وصف النطاق والاستخدام والقيود وخطة التحسين، راجع [بطاقة مجموعة البيانات](DATASET_CARD.md).

## التحقق البنيوي وتوسيع البيانات / Validation and annotations

يمكن تشغيل المدقق المحلي دون تثبيت حزم خارجية:

```bash
python scripts/validate_dataset.py
python -m unittest discover -s tests -v
```

يُتحقق المدقق من بنية JSON، وعدد المدخلات والفئات، وفريدة المعرّفات، واتساق أعداد الفئات. ويعمل GitHub Actions تلقائياً عند تغيير البيانات أو المدقق أو الاختبارات.

مرجع البنية هو [JSON Schema](data/schema.json). الحقول الحالية متوافقة مع الإصدار القديم؛ ويمكن إضافة التعليقات المنهجية الاختيارية تدريجياً، دون اختلاق معلومات غير موثقة:

- `entry_type`: نوع المدخل.
- `region` و`context` و`register`: المنطقة والسياق ومستوى الاستعمال، عند توفر دليل.
- `provenance`: المصدر وصاحب الحقوق وأذونات إعادة التوزيع والتدريب والاستخدام التجاري، كلٌّ على حدة.
- `review`: حالة المراجعة البشرية.

تُستخدم القيمة `unknown` أو حالة `pending` عندما لا تتوفر أدلة كافية. لا تُعدّ نتائج المدقق البنيوي تصديقاً لغوياً أو قانونياً. ملف [manifest template](data/manifest.template.yaml) قالب توثيقي، وليس إقراراً بأن الحقوق قد دُققت.
