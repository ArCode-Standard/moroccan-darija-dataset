# سياسة جمع بيانات الدارجة | Data Collection Protocol

## 1. نطاق الجمع

اجمع فقط المادة اللازمة لغرض لغوي محدد، مثل توثيق مفردة أو معنى أو مثال أو تنوع نطقي. لا تجمع محادثات خاصة أو بيانات شخصية لمجرد زيادة حجم المجموعة.

## 2. طرق الجمع المقبولة مبدئياً

- مساهمة طوعية مباشرة من متحدث أو مساهم، مع توضيح الاستخدامات المقصودة.
- مقابلة لغوية منظمة بعد الحصول على موافقة صريحة ومفهومة.
- مصادر منشورة تسمح شروطها والترخيص بإعادة الاستخدام المقصود.
- بيانات اصطناعية موسومة بوضوح، مع حفظ النموذج والموجه وإصدار التوليد وعدم تقديمها على أنها كلام بشري.

لا تعني هذه القائمة أن أي مصدر بعينه مسموح تلقائياً؛ يجب تقييم كل مصدر وشروطه.

## 3. الحد الأدنى من بيانات الجمع

سجل، عندما تكون المعلومات متاحة ومصرحاً بها:
- `collection_id` ومعرفات سجلات ثابتة.
- نوع المصدر: contributor / interview / published_source / synthetic / unknown.
- تاريخ الجمع أو تاريخ الوصول، مع عدم اختلاق تاريخ رجعي.
- طريقة الجمع والأداة أو بروتوكول المقابلة.
- اللغة/التنوع والمنطقة على مستوى الدقة التي وافق عليها المشارك.
- عدد المساهمين أو المتحدثين فقط إذا تم إحصاؤهم فعلياً.
- نص الموافقة ونطاقها أو مرجعها، ومجالات الاستخدام المسموحة.
- عمليات التنظيف والتطبيع والترجمة والتحويل وإصدارات الأدوات.
- حالة المراجعة اللغوية والحقوقية كل على حدة.

استخدم `null` أو `unknown` عند عدم توفر معلومة. لا تستنتج العمر أو المنطقة أو الأصل الاجتماعي من اللغة.

## 4. موافقة المشاركين والخصوصية

قبل تسجيل الصوت أو النصوص الشخصية:
- اشرح الغرض، وطبيعة البيانات، ومكان التخزين، ومن يمكنه الوصول إليها.
- احصل على موافقة صريحة منفصلة للتسجيل، والنشر، والتدريب، والاستخدام التجاري.
- اجعل الانسحاب وطريقة طلب حذف البيانات واضحين.
- لا تجمع أسماء أو أرقام هواتف أو عناوين دقيقة في مجموعة البيانات المنشورة.
- استخدم معرفات مستعارة وافصل بيانات الاتصال عن البيانات اللغوية.
- لا تنشر الصوت أو الاقتباسات التي قد تكشف هوية الشخص دون إذن مناسب.

## 5. النصوص المنشورة على الإنترنت

إمكانية الوصول إلى صفحة عامة لا تعني الإذن بإعادة نشرها أو تدريب نموذج عليها. افحص:
- شروط الخدمة والترخيص الساري وقت الجمع.
- حقوق المؤلف والحقوق المجاورة وقواعد البيانات.
- القيود التقنية أو التعاقدية ذات الصلة.
- حقوق التعريفات والترجمات والأمثلة، لا الكلمات وحدها.
- ما إذا كان الاستخدام يسمح بالتخزين أو الاشتقاق أو التدريب أو التوزيع.

إذا لم تتضح الحقوق، سجّل الحالة `unknown` ولا تدرج المادة في صادرات التدريب أو التوزيع إلى حين التحقق.

## 6. التوازن الجهوي

لا تضع وسم منطقة إلا إذا وردت من مصدر الجمع أو المشارك. سجل locality المبلغ عنها لكل عنصر أو دفعة، ولا تعمم ملاحظة شخص واحد على جهة كاملة. انشر أعداد التغطية فقط عندما تكون طريقة العد موثقة.

## 7. الفصل بين البشري والاصطناعي

يجب أن تحمل البيانات الاصطناعية حقولاً واضحة مثل `origin: synthetic`, `generator`, `model_version`, `prompt_version` و`review_status`. لا تخلطها مع النص البشري دون وسم، ولا تستخدمها في مجموعة الاختبار المرجعية.

## 8. بوابة قبول أي دفعة

لا تقبل دفعة للنشر قبل:
1. وجود وصف واضح لطريقة الجمع.
2. تحديد مصدرها وصاحب الحق أو توضيح أن ذلك غير معروف.
3. تسجيل أذونات إعادة التوزيع والتدريب والتجاري كل على حدة.
4. اجتياز التحقق البنيوي.
5. مراجعة عينة لغوية بشرية موثقة.
6. فحص الخصوصية وإزالة البيانات الشخصية غير اللازمة.
