# بنية البيانات | Data Structure

## الهدف

توحيد طريقة تخزين موارد الدارجة المغربية مع الحفاظ على التوافق مع ملفات الإصدارات الحالية. لا تعني البنية أن جميع أنواع البيانات المذكورة موجودة بالفعل.

## الموارد الحالية

| المسار | النوع | الحالة |
|---|---|---|
| `data/moroccan-darija.json` | المعجم الوطني | إصدار معلن 1.11.0 |
| `data/context-examples.json` | أمثلة سياقية مرتبطة بمعرّفات المعجم | 146 مثالاً معلناً |
| `data/regions/north.json` | مفردات إقليمية أولية | 122 مدخلاً، pending |
| `data/sources/registry.json` | فهرس مركزي لعائلات المصادر | توثيق تجميعي؛ ليس تدقيقاً قانونياً |
| `data/schema.json` | مخطط المعجم الحالي | مستخدم من المدقق |
| `data/context-schema.json` | مخطط الأمثلة السياقية | مستخدم من المدقق |
| `data/schemas/regional-lexicon.schema.json` | مخطط الموارد الإقليمية | مخطط أولي للمراجعة |

## القواعد المعمارية

1. **افصل أنواع البيانات:** المعجم، الأمثلة، المتون، البيانات المتوازية، التعليمات، التقييم، والصوت موارد مختلفة، ولكل منها مخطط وحقوق ومنهجية.
2. **ثبّت المعرّفات:** لا تعِد استخدام ID ولا تغيّره عند تحرير المعنى أو الإملاء.
3. **وثّق المنشأ:** يجب أن يمكن تتبع المصدر والتحويلات والإذن لكل سجل أو دفعة متجانسة.
4. **افصل المراجعات:** المراجعة اللغوية والحقوقية والتحقق الآلي ثلاث عمليات مستقلة.
5. **لا تفترض الجغرافيا:** المنطقة المبلغ عنها ليست إثباتاً للانتشار أو الحصرية.
6. **احفظ الأصل:** احتفظ بالصيغة التي قدمها المساهم، وأضف المتغيرات دون محو الأصل.
7. **التوافق أولاً:** لا تنقل الملفات الحالية أو تغير أسماءها قبل توفير ترحيل واختبارات وروابط انتقالية.

## البنية المستهدفة تدريجياً

```text
data/
├── lexicon/                 # فصل مستقبلي للمعجم بعد ترحيل متوافق
├── regions/
│   ├── north.json           # الملف الحالي؛ يحافظ على المسار
│   └── README.md
├── corpus/                  # لا يُنشأ قبل توفر corpus مرخص وموثق
├── parallel/                # أزواج لغوية محاذاة ومراجعة
├── instructions/             # تعليمات موسومة بمصدرها
├── evaluation/               # مجموعات تقييم مستقلة ومحجوبة
├── speech/                   # صوت وموافقات وبيانات وصفية
├── sources/
│   └── registry.json
└── schemas/
    └── regional-lexicon.schema.json
```

المجلدات المستقبلية في الرسم ليست ملفات بيانات متاحة حالياً. أنشئها عند توفر مورد حقيقي ومراجعته.

## ملفات البيانات والسجلات

### المعجم الوطني

يحافظ حالياً على الحقول الأساسية `id`, `category`, `darija_ar`, `darija_latin`, `fusha_ar`, `fr`، مع حقول `provenance` و`review` وحقول اختيارية أخرى حسب المخطط.

### الأمثلة السياقية

تبقى في ملف مستقل وترتبط بالمعجم عبر `entry_id`. لا تكرر نص المثال في المعجم الأساسي.

### البيانات الإقليمية

تستخدم معرفات مستقلة مثل `north-001`، ولا تتداخل مع IDs الرقمية للمعجم الوطني. كل عنصر يحتاج إلى موقع مبلغ عنه ومراجعة مستقلة عندما تتوفر هذه المعلومات.

### سجل المصادر

`data/sources/registry.json` يجمع بيانات المصدر على مستوى المصدر/العائلة. لا يغني عن provenance على مستوى السجل، ولا يثبت الإذن القانوني.

## التطوير دون كسر التوافق

قبل أي نقل من `data/moroccan-darija.json` إلى `data/lexicon/entries.json`:
- أضف نسخة انتقالية أو alias موثقاً.
- حدّث جميع المستهلكين والوثائق.
- قارن عدد السجلات وIDs ومحتوى JSON قبل وبعد.
- شغّل الاختبارات على الملفين.
- لا تحذف المسار القديم في نفس التغيير الذي يقدم المسار الجديد.
