# AWAL — خطة جمع الدارجة المغربية (الإصدار 0.1)

## الاستراتيجية المعتمدة

- **النطاق:** الدارجة المغربية المعاصرة العامة.
- **الكتابة:** العربية وعربيزي/اللاتينية في حقليْن متوازييْن، مع الاحتفاظ بالبدائل عند توثيقها لاحقاً.
- **أنواع المادة:** مفردات، تعابير، جمل، أسئلة، أجوبة، وأدوار حوارية.
- **التغطية:** جميع مناطق المغرب؛ التغطية هدف جمع وليست ادعاءً بأن العينة الحالية تمثل كل المناطق.

## ما أُنشئ في المرحلة الأولى

- `data/collection/awal-seed-v0.1.jsonl`: 32 مثالاً اصطناعياً أولياً موزعة على المفردات والتعابير والجمل والأسئلة والأجوبة وأدوار الحوار.
- `data/schemas/awal-collection-record.schema.json`: مخطط موحد للسجل الثنائي الكتابة.
- `scripts/validate_awal_collection.py`: مدقق للمخطط، تفرد المعرفات والنصوص، مصدر السجل، ووسم المنشأ الاصطناعي.
- `data/sources/registry.json`: مصدر مستقل للدفعة الاصطناعية، دون منح أي إذن تدريبي أو تقييمي.

## تفسير الدفعة الاصطناعية

هذه الأمثلة صيغت كبداية تحريرية لتجريب بنية الجمع والمراجعة. ليست تفريغاً لكلام متحدثين، ولا بيانات ميدانية، ولا دليلاً على شيوع أي صيغة في منطقة معينة. يجب على مراجعين ناطقين بالدارجة تصحيحها وتوثيق البدائل والسياقات قبل اعتمادها.

تبقى جميع السجلات:
- `origin=synthetic`
- `review_status=pending`
- `rights_review_status=unknown`
- `training_permission=unknown`
- `evaluation_permission=not_allowed`

لا تُستخدم هذه الدفعة في مجموعة الاختبار المرجعية، ولا تصبح مؤهلة للتدريب تلقائياً. أي قرار لاحق يتطلب مراجعة لغوية وحقوقية منفصلة، ثم المرور عبر بوابة AWAL Training Eligibility.

## قواعد التغطية الجهوية

لا يملأ `region_claim` بالتخمين. يظل `null` إلى أن يقدّم المساهم منطقة الاستعمال أو توثقها مقابلة/مصدر محدد. تسجل المدينة أو المنطقة المبلغ عنها فقط، ولا تُعمم على جهة كاملة. يجب جمع عينات مستقلة من الشمال والشرق والوسط والجنوب والجنوب الشرقي والمناطق الساحلية والداخلية، مع مراعاة التنوع الحضري والقروي دون افتراض تمثيل متوازن مسبقاً.

## بروتوكول الدفعات التالية

1. جمع مساهمات طوعية أو مقابلات بموافقة صريحة، مع فصل بيانات الاتصال عن المحتوى اللغوي.
2. لكل سجل: الصيغة العربية، الصيغة اللاتينية، بدائل الكتابة، المعنى، جملة طبيعية، ونطاق الاستعمال إذا كان معروفاً.
3. تسجيل مصدر محدد ومحدد موضع (locator) لكل سجل، وعدم الاكتفاء برابط الصفحة الرئيسية.
4. فصل مراجعة اللغة عن مراجعة الحقوق والخصوصية.
5. الاحتفاظ بالسجل الأصلي وعدم استبداله بتطبيع غير موثق.
6. عدم نقل أي سجل إلى التدريب أو التقييم قبل الإذن الصريح والمراجعة المستقلة.

## التحقق

```bash
python scripts/validate_awal_collection.py
```

نجاح المدقق يثبت سلامة البنية والسياسة المعلنة فقط؛ ولا يثبت صحة لغوية أو تمثيلاً جهوياً أو أهلية قانونية.
