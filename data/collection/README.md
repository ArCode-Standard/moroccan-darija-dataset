# Collection workspace

This directory is reserved for controlled collection batches.

- Do not commit private messages, user profiles, contact details, account identifiers, or raw content without documented rights.
- Keep source metadata in the central registry.
- Keep lexical candidates separate from approved lexicon entries.
- Keep corpus document metadata separate from corpus payloads.
- Never place restricted raw material in this public repository.
- Candidate IDs use `CAND-000001`; document IDs use `DOC-000001`.
- Unknown permissions block public redistribution and model training.
